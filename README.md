# Akshaj Nadimpalli — Portfolio

A responsive static portfolio for Summer 2027 software engineering internships. Hosted on GitHub Pages at https://www.akshajnad.tech/.

## Local preview

Run `python3 -m http.server 4173` and open http://localhost:4173. No build or dependencies are required.

## Contents

- `index.html`: experience, selected work, metadata, and accessible markup.
- `styles.css`: responsive layout, reduced-motion support, and print styles.
- `interactions.js`: engineering-focus controls, project disclosures, and email copy.
- `script.js`: local keyword-based portfolio search; no external API or transmitted queries.
- `assets/`: original portfolio artwork, Akshaj's portrait from Signifi, and an actual EchoLocate product capture.

## Content provenance

Role and project metrics come from the existing portfolio/resume. Keep `CNAME` set to `www.akshajnad.tech`. GitHub Pages deploys the root of `main`.
